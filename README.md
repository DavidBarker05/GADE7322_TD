# GADE7322_TD

Developed with Unreal Engine 5

As I was working solo for this I decided to code more similar to how I normally would with some formal and informal comments here-and-there for how I was feeling (although more filtered as this is an assignment).

I am also not an artist I am a programmer, so all of the assets (except one) I got from online. I also tried to do this entire project in C++ as far as Unreal would let me (and also what seemed reasonable).
